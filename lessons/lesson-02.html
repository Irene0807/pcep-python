判斷與迴圈

讓程式依條件走不同路，或重複做同一件事

這課學完會

  • 寫 if / elif / else
  • 寫 while、for，會用 range() 三個參數
  • 分得出 break、continue、pass
  • 知道迴圈的 else 什麼時候會跑

2.1 條件判斷

if / elif / else

  • 由上往下檢查，第一個成立的就做，其他跳過
  • elif 可以很多個，else 最多一個、放最後
  • 條件後面要冒號，區塊要縮排
score = 75
if score >= 90:
    print("A")
elif score >= 70:
    print("B")
elif score >= 60:
    print("C")
else:
    print("F")

2.2 迴圈

while

  • 條件成立就一直做，記得更新變數不然會無限迴圈
  • while ... else：條件變 False 正常結束時跑 else
i = 0
while i < 3:
    print("=", i)
    i += 1
else:
    print("stop, i =", i)

for + range()

  • range(stop)：0 到 stop-1
  • range(start, stop)、range(start, stop, step)
  • step 可以是負的，倒著數
for i in range(5):
    print(i, end=" ")
print()
for i in range(2, 10, 3):
    print(i, end=" ")
print()
for i in range(5, 0, -2):
    print(i, end=" ")

用 for 走 list

  • 要 index：for i in range(len(arr))
  • 只要值：for item in arr
arr = ["a", "c", "r", "k"]
for i in range(len(arr)):
    print(i, arr[i])
for item in arr:
    print(item, end=" ")

巢狀迴圈

  • 外圈跑一次，內圈整個跑完
  • 總次數 = 外圈次數 * 內圈次數
for i in range(1, 4):
    for j in range(1, 4):
        print(i * j, end="\t")
    print()

2.3 break / continue / pass

三個的差別

  • break：整個迴圈直接結束
  • continue：跳過這一輪，進下一輪
  • pass：先佔位，什麼都不做
arr = ["a", "c", "r"]
for item in arr:
    if item == "c":
        break
    print("break:", item)
for item in arr:
    if item == "c":
        continue
    print("continue:", item)
for item in arr:
    if item == "c":
        pass
    print("pass:", item)

常見陷阱

迴圈的 else 被 break 跳過

沒有 break、正常跑完才會進 else

for n in [3, 5, 8]:
    if n % 2 == 0:
        print("found even", n)
        break
else:
    print("no even")

for n in [3, 5, 7]:
    if n % 2 == 0:
        break
else:
    print("no even")

range 不包含 stop

range(1, 5) 只到 4；step 不能是 0

print(list(range(1, 5)))
print(list(range(10, 0, -3)))
print(list(range(5, 1)))

迴圈結束後變數還在

for 跑完，迴圈變數停在最後一個值

for i in range(3):
    pass
print(i)

while 0 次也會進 else

一開始條件就 False，迴圈不跑，但 else 照跑

i = 10
while i < 3:
    print("in loop")
else:
    print("else")

小測驗

點選項作答，會直接顯示對錯

1. 下面程式會印出什麼？

for i in range(1, 10, 3):
    print(i, end=" ")
  1. 1 4 7
  2. 1 4 7 10
  3. 1 3 6 9
  4. 3 6 9

解析：從 1 開始每次加 3，到 10 之前停

2. 下面程式會印出什麼？

i = 0
while i < 3:
    i += 1
else:
    print("done", i)
  1. done 2
  2. 什麼都沒印
  3. done 3
  4. done 4

解析：i 加到 3 條件變 False，正常結束所以跑 else

3. 下面程式會印出什麼？

for c in "abc":
    if c == "b":
        break
else:
    print("no break")
print(c)
  1. no break
    c
  2. b
  3. no break
    b
  4. c

解析：遇到 b 就 break，else 被跳過，c 停在 "b"

4. 下面程式會印出什麼？

total = 0
for i in range(5):
    if i % 2 == 0:
        continue
    total += i
print(total)
  1. 10
  2. 6
  3. 0
  4. 4

解析：偶數被 continue 跳過，只加 1 + 3 = 4

5. * 總共印幾次？

for i in range(3):
    for j in range(i):
        print("*")
  1. 9
  2. 6
  3. 3
  4. 0

解析：i = 0, 1, 2，內圈分別跑 0、1、2 次，共 3 次
