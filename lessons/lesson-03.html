3.2 List

宣告、取用、常用函式

  • 宣告 a = []
  • 取用 a[0]、最後一個 a[-1]，可以直接改 a[0] = 100
  • sum()、max()、min()、len()
a = [10, 20, 30, 40]
print(a[0], a[-1])
a[0] = 100
print(a)
print(sum(a), max(a), min(a), len(a))

加、減、排序

  • 加：append(x) 加最後、insert(i, x) 插在位置 i
  • 減：del a[i] 刪位置、remove(x) 刪第一個 x、pop() 拿出最後一個
  • 排序：a.sort() 改原本的；sorted(a) 回傳新的
  • count(x) 算 x 出現幾次
a = [30, 10, 20]
a.append(40)
a.insert(1, 99)
print(a)
del a[1]
a.remove(40)
x = a.pop()
print(a, x)
b = sorted(a)
a.sort(reverse=True)
print(a, b, a.count(10))

切片、in、enumerate

  • a[start:stop:step]，跟 range 一樣不包含 stop
  • a[::-1] 倒過來
  • in / not in 檢查值在不在
  • enumerate(a) 同時拿 index 跟值
a = [0, 1, 2, 3, 4, 5, 6, 7, 8]
print(a[1:4], a[-2:-1], a[1:8:2], a[::-1])
print(20 in a, 20 not in a)
for i, j in enumerate(["apple", "banana", "cat"]):
    print(i, j)

List Comprehension

  • [運算 for i in 範圍] 一行建 list
  • 後面可以加 if 篩選
a = []
for i in range(5):
    a.append(i * 2)
print(a)
print([i * 2 for i in range(5)])
print([i for i in range(10) if i % 3 == 0])

3.3 Tuple

不能改的 list

  • 宣告 a = ()；只有一個值要加逗號 (1,)
  • 取用、切片、in、len()、count() 跟 list 一樣
  • 沒有 append、remove、sort，要排序用 sorted() (回傳 list)
  • 互轉：tuple(my_list)、list(my_tuple)
a = (30, 10, 20)
print(a[0], a[-1], a[1:], len(a))
print(sorted(a))
print(tuple([1, 2]), list((1, 2)))
a[0] = 100

解包、當 dict 的 key

  • 解包：x, y = point，左右數量要一樣
  • tuple 不能改，所以可以當 dict 的 key (list 不行)
point = (3, 5)
x, y = point
print(x, y)
d = {(1, 2): "point A", (3, 4): "point B"}
print(d[(1, 2)])

3.4 Dictionary

取用

  • 宣告 a = {}，裝 key: value
  • a["id"] 找不到會錯；a.get("id") 找不到回傳 None，比較安全
  • keys()、values()、items()
  • in 檢查的是 key，不是 value
a = {"id": 18, "name": "Amy"}
print(a["id"], a.get("age"), a.get("age", 0))
print(list(a.keys()), list(a.values()))
for key, value in a.items():
    print(key, value)
print("id" in a, 18 in a)

加、改、刪

  • a[key] = value：key 已經有就改，沒有就加
  • 刪：del a[key]、a.pop(key, None) (找不到不會錯)
  • sorted(a.items()) 照 key 排
a = {"id": 18}
a["id"] = 25
a["name"] = "Irene"
print(a)
x = a.pop("id", None)
print(x, a, a.pop("age", None))
print(sorted({"b": 2, "a": 1}.items()))

3.5 String

取用跟切片

  • 取用、切片、in、len()、count() 跟 list 一樣
  • string 不能改：s[0] = "K" 會錯
s = "hello"
print(s[0], s[-1], s[1:4], s[::-1])
print("h" in s, len(s), s.count("l"))

常用方法

  • 大小寫：upper()、lower()、capitalize()
  • 去空白：strip()、lstrip()、rstrip()
  • replace(old, new)、split(sep) -> list、"-".join(list) -> string
  • 這些都回傳新字串，原本的 s 不變
s = "  hello  "
print("[" + s.strip() + "]", "[" + s.rstrip() + "]")
s = "hello"
print(s.upper(), s.capitalize(), s.replace("l", "x"))
print(s)
word = "a,b,c".split(",")
print(word, "-".join(word))

常見陷阱

b = a 不是複製

list、dict 用 = 只是兩個名字指同一個，改 b 也會改到 a

a = [1, 2, 3]
b = a
c = a.copy()
b.append(4)
print(a, b, c)

(1) 不是 tuple

只有一個值要加逗號，不然就只是括號

print(type((1)), type((1,)), type(()))

tuple 裡的 list 可以改

tuple 本身不能換元素，但裡面的 list 自己可以變

a = (10, [20, 30], 40)
a[1][1] = 25
print(a)
a[0] = 25

sort() 回傳 None

a.sort() 直接改 a，沒有回傳值；要拿新的 list 用 sorted()

a = [3, 1, 2]
b = a.sort()
print(a, b)

string 方法不會改原本的

沒有把結果存起來就等於沒做

s = "hello"
s.upper()
print(s)
s = s.upper()
print(s)

小測驗

點選項作答，會直接顯示對錯

1. 下面程式會印出什麼？

a = [1, 2, 3]
b = a
b[0] = 9
print(a)
  1. [1, 2, 3]
  2. [9]
  3. [9, 2, 3]
  4. Error

解析：a、b 指同一個 list，改 b 就是改 a

2. 下面程式會印出什麼？

a = [0, 1, 2, 3, 4, 5]
print(a[1:5:2], a[-2:])
  1. [1, 3] [4, 5]
  2. [1, 3, 5] [4, 5]
  3. [1, 3] [4]
  4. [2, 4] [4, 5]

解析：1 開始每次跳 2，到 5 之前停 -> 1、3；-2 到最後 -> 4、5

3. 哪一個會出錯？

  1. t = (1, [2, 3]); t[1].append(4)
  2. d = {(1, 2): "A"}
  3. s = "hi"; s = s + "!"
  4. s = "hi"; s[0] = "H"

解析：string 不能改元素；C 是建一個新字串再指回 s，可以

4. 下面程式會印出什麼？

d = {"a": 1, "b": 2}
d["a"] = 5
d["c"] = 3
print(len(d), d.get("x"))
  1. 4 None
  2. 3 None
  3. 3 Error
  4. 2 0

解析："a" 已經有，是修改；"c" 是新增，共 3 個 key；get 找不到回傳 None

5. 下面程式會印出什麼？

print([i * i for i in range(5) if i % 2 == 1])
  1. [0, 4, 16]
  2. [1, 3]
  3. [1, 9]
  4. [1, 9, 25]

解析：range(5) 的奇數是 1、3，平方 -> 1、9

6. 下面程式會印出什麼？

s = "a-b-c"
print(s.split("-"), "".join(s.split("-")))
  1. ['a', 'b', 'c'] abc
  2. ['a-b-c'] a-b-c
  3. ['a', 'b', 'c'] a b c
  4. abc ['a', 'b', 'c']

解析：split 切成 list，用空字串 join 接起來中間沒東西
