1.1 基本名詞

程式語言

  • 自然語言：人講的話；機器語言：0 跟 1
  • Python 是高階語言，介在兩者中間
  • CPython：官方預設版本，用 C 寫的
  • 名字來自英國喜劇 Monty Python's Flying Circus，不是蟒蛇
  • Console：直接跟 Python 一行一行互動；IDLE：內建的簡單編輯器；Script：存成 .py 的程式檔

編譯 vs 直譯

編譯 Compilation直譯 Interpreting
做法全部翻完再執行邊翻邊執行
例子C / C++ (.c -> .exe)Python (.py)
優點執行快寫完直接跑、好除錯、跨平台
缺點編譯久、不好跨平台每次都要翻，比較慢；錯誤跑到那行才發現

lexis / syntax / semantics

  • lexis 詞彙：切得出合法的 token (英文：Bpple 不是字)
  • syntax 語法：符合規則 (英文：Love I you.)
  • semantics 語意：有意義 (英文：I am a apple.)
# 語法都對，跑到第 2 行才出事 -> semantics 錯
print("start")
print(10 / 0)

1.2 程式結構

keyword、縮排、註解

  • keyword 保留字不能當變數名稱，用 keyword.iskeyword() 查
  • 縮排決定區塊，建議 4 個空格
  • 單行註解 #，VS Code 選多行按 ctrl + /
import keyword
print(keyword.iskeyword("for"))
print(keyword.iskeyword("hello"))
print(len(keyword.kwlist), "keywords")

1.3 資料型態與進位

5 種基本型態

  • int：1000、-5、0
  • float：25.5、科學記號 3e8 = 3 * 10^8
  • str："56"
  • bool：True、False (首字大寫)
  • None：什麼都沒有
print("5" + "6")
print(5 + 6)
print(3e8, type(3e8))
print(type(None))

4 種進位

  • 十進位：26
  • 二進位 0b：0b11010
  • 八進位 0o：0o32
  • 十六進位 0x：0x1A (每位 0-9 + A-F)
print(0b11010, 0o32, 0x1A)
print(bin(26), oct(26), hex(26))

變數命名

  • 只能有英文、數字、底線 _
  • 不能數字開頭、大小寫有差、不能用 keyword
  • PEP 8：變數小寫加底線 max_size、常數全大寫 PI、class 字首大寫 MyClass
  • PEP 8：運算子左右空格、縮排 4 格 (建議，不是強制)

1.4 運算子

數學運算

  • ** 次方，由右往左算
  • / 一定得到 float；// 整除 (往負無限大取整)；% 餘數
  • 優先級：() > ** > 正負號 > * / // % > + -
print(2 ** 3 ** 2)
print(10 / 2, 7 // 2, 7 % 2)
print(-2 ** 2)
print(2 + 3 * 4 ** 2)

字串、比較、布林

  • 字串：+ 接起來、* 重複
  • 比較：== != > < >= <=，結果是 bool
  • 布林：not > and > or
  • 總優先級：數學 > 比較 > 布林
print("a" * 3 + "b" * 2)
print(3 > 2 and not 1 == 1)
print(True or False and False)

位元運算

  • & 兩邊都 1、| 一邊是 1、^ 不一樣才 1
  • ~x = -x - 1
  • << n 左移 = 乘 2^n、>> n 右移 = 除 2^n 取整
a, b = 0b0011, 0b0101
print(a & b, a | b, a ^ b)
print(~25)
print(25 << 2, 25 >> 2)

float 精準度

  • float 用二進位存，只是很接近的值
  • 比較 float 不要直接 ==
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
print(round(0.1 + 0.2, 2) == 0.3)

1.5 輸入輸出

print()

  • print(*objects, sep=" ", end="\n")
  • sep：中間用什麼隔，預設空格；end：結尾加什麼，預設換行
print("a", "b", "c")
print("a", "b", "c", sep="-")
print("no newline", end="!")
print("next")

input() 跟型態轉換

  • input() 拿到的一定是 str，要算數字先轉
  • int()、float()、str()、bool()
  • bool 是 False 的：0、0.0、""、None、空的容器
x = input("number: ")
print(type(x))
print(int(x) * 2)

print(int(3.6), int("12"))
print(float(3), float("12"), float(True))
print(str(12.5), str(True))
print(bool(0), bool("Hello"), bool(""), bool("    "))

常見陷阱

** 由右往左

2 ** 3 ** 2 先算 3 ** 2；負號比 ** 慢，-2 ** 2 是 -4

print(2 ** 3 ** 2, (2 ** 3) ** 2)
print(-2 ** 2, (-2) ** 2)

負數的 // 跟 %

// 往負無限大取，不是直接砍小數

print(-7 // 2, int(-7 / 2))
print(-7 % 3, 7 % -3)

int() 轉不了小數字串

int("3.6") 會錯，要先 float()

print(int(float("3.6")))
print(int("3.6"))

空白字串是 True

只有完全空的 "" 才是 False

print(bool(" "), bool(""), bool("0"))

小測驗

點選項作答，會直接顯示對錯

1. 下面程式會印出什麼？

print(2 ** 3 ** 2)
  1. 64
  2. 512
  3. 81
  4. Error

解析：** 由右往左，3 ** 2 = 9，2 ** 9 = 512

2. 下面程式會印出什麼？

print(-7 // 2)
  1. -3
  2. -4
  3. -3.5
  4. 3

解析：-3.5 往負無限大取整 = -4

3. 哪一個不是合法的變數名稱？

  1. _count
  2. count2
  3. 2count
  4. Count

解析：不能用數字開頭

4. 下面程式會印出什麼？

print(0o17 + 0b11)
  1. 28
  2. 20
  3. 0o20
  4. 18

解析：0o17 = 1*8 + 7 = 15，0b11 = 3，15 + 3 = 18，print 印十進位

5. 下面程式會印出什麼？

print("a", "b", sep="*", end="#")
print("c")
  1. a*b#c
  2. a*b#
    c
  3. a b*#c
  4. ab*#c

解析：sep 放在 a、b 中間，end 取代換行，所以 c 接在同一行

6. 下面程式會印出什麼？

print(bool(" "), bool(0.0), float(True))
  1. False False 1
  2. True True 1.0
  3. True False 1.0
  4. False False 1.0

解析：空白字串不是空的 -> True；0.0 -> False；True 轉 float 是 1.0
